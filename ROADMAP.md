# Talkboard public roadmap

## Current release work

Prepare the 0.2.0 public beta: illustrated generic communication pages, a blank
People page for user-supplied content, and a separate ABC / 123 activity.
The app uses a distinct public bundle identifier. No personal boards, recordings,
photos, device identifiers or signing credentials are distributed.

Code: Apache 2.0. Bundled artwork retains separate attribution and license terms;
see THIRD_PARTY_NOTICES.md. Automated tests check software behavior, not language
benefit or every installed voice's audible pronunciation.

## Open work

- Audition and improve all alphabet letter names; A, E and G have reported issues.
- Choose alphabet song audio and implement interruption-safe highlighting.
- Deliberate number-counting playback.
- Validated export/restore, printed fallback and recording import/capture.
- Physical-device idle audio, Guided Access and accessibility acceptance.
- General saved multi-page editing; current vocabulary pages are transient.
